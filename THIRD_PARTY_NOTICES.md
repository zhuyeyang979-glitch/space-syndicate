# Space Syndicate Third-Party Notices

This distribution includes only the fixed commercial-art source set recorded in
`docs/third_party/selected_commercial_asset_manifest.json`. Runtime assets are
packaged locally; the game does not download art, audio, models, or fonts.

## MIT License Asset

The planet body, cloud, and atmosphere shader foundation is extracted from
Naejimer's Godot 3D Planet Generator, distributed under the MIT License. The
packaged license is retained at:

`assets/third_party/commercial/planet/naejimer_planet_generator/LICENSE`

Only the required shader foundation and minimal support resources are used;
the demo project is not a production dependency.
